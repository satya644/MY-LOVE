# Shubh Deepawali - Animated Friendship Website 🪔✨

Is folder mein aapki website GitHub Pages par upload karne ke liye bilkul ready hai:
- `index.html` (Main website file jo `images/photo1.jpg` se `images/photo9.jpg` ko load karti hai)
- `images/` folder (Aapki sabhi 9 photos easy naam `photo1.jpg` ... `photo9.jpg` ke saath)

## GitHub Par Kaise Upload Karein:
1. GitHub.com par login karein aur **New Repository** banayein (Naam rakhein jaise: `diwali-dosti` aur **Public** select karein).
2. **uploading an existing file** link par click karein.
3. Is ZIP ko unzip karke iske andar ki `index.html` file aur poora `images` folder drag-and-drop kar dein.
4. Neeche **Commit changes** button dabayein.
5. Ab Repository ke **Settings -> Pages** mein jayein, **Branch** mein `main` select karke **Save** kar dein.
6. 1 minute mein aapka live website link tayyar ho jayega!
